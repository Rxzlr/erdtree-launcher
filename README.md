# Erdtree Launcher

لانشر عربي (RTL) لإلدن رينغ، بواجهة داكنة بلمسة ذهبية، وبدون خطوات تقنية معقّدة. يفتح على **حساب شخصي** (أو Guest)، وبعدها سبعة أقسام: تشغيل اللعبة، الأصدقاء، البيلدات، الورشة، **MY SAVES**، **UNLOCK ALL**، والاعدادات. التعديلات الأوفلاين صارت أداة داخل الاعدادات. تقدر تبدّل لغة الواجهة بين **العربية** و**English** من زر `EN` في الشريط العلوي أو من الاعدادات، والاختيار ينحفظ. القسمان الجديدان إنجليزيان LTR بنفس الطابع.

الإصدار الحالي: **2.6.1**

2.6.1: إصلاح التقاط التحميل من نافذة نيكسس الداخلية — كان حجب النطاقات يمنع التحميل لأن نيكسس يسلّم الملفات من نطاقه الرسمي `files.nexus-cdn.com`؛ الآن يُسمح لنطاقات نيكسس وملفاته فقط، ويبقى ما عداها محجوباً.

## الحساب — تسجيل الدخول والحفظ

- أول فتح يعرض شاشة حساب فخمة: **Log in** (اسم المستخدم أو الإيميل + كلمة السر)، **Create Account** (اسم، إيميل، كلمة سر، تأكيد)، **Login as Guest**، **Forgot Password?**، و**Remember Me**.
- كلمة السر تُحفظ مشفّرة بـ `scrypt` مع salt، والجلسة تُحفظ بـ token مجزّأ (sha256) لمدة 45 يوم إذا فعّلت **Remember Me**.
- بعد الدخول يظهر أعلى الشريط الجانبي صورتك واسمك ومستواك. اضغط البطاقة لتفتح قائمة الحساب: **Edit profile**، **Change profile picture**، إعدادات اللانشر، و**Sign out**.
- كل حساب له مجلد بيانات خاص: الأصدقاء، البيلدات، الإعدادات، الشخصيات، النسخ الاحتياطية، والمودات — فما تختلط بيانات حساب بحساب.
- **Guest** يقدر يلعب ويجرّب، لكن **ما ينحفظ له شي**: جلسة الضيف ومجلده المؤقت يُمسحان عند الخروج، والجلسة ما ترجع بعد إعادة التشغيل.
- **Forgot Password?** يعرض **كود استرجاع** بصيغة `ERD-XXXX-XXXX-XXXX` عند إنشاء الحساب؛ احفظه. تغيير كلمة السر بكود الاسترجاع ينتج كود استرجاع جديد ويبطل القديم.
- **حد صريح:** هذه حسابات محلية على هذا الجهاز (بدون سيرفر مركزي)، فما فيه استرجاع عبر الإيميل — كود الاسترجاع هو طريقك الوحيد.

## التشغيل السريع

### المتطلبات

- Windows 10/11 (64-bit)
- Node.js 22 أو أحدث (مع npm)
- اتصال بالإنترنت لأول `npm install`، ولتحميل المودات من مصادرها المجانية أو من نافذة نيكسس الداخلية. باقي اللانشر يشتغل أوفلاين.

### أول مرة

```bash
npm install
npm start
```

أو بضغطة مزدوجة على `start.bat` (يثبّت المتطلبات أول مرة ثم يشغّل اللانشر).

بعد ما يفتح اللانشر:

1. **معالج أول مرة** يفتح تلقائياً: يدوّر على اللعبة (من ستيم، أو عملية اللعبة الشغالة، أو مجلدات `C:\Games\ELDEN RING` المعتادة)، وتقدر تختار ملف التشغيل يدوياً.
2. اكتب **كلمة سر Seamless** — نفسها لازم تكون عندك وعند كل أخوياك — وثبّت Seamless بضغطة إذا مو مثبّت.
3. اختر وضع التشغيل الافتراضي (**Normal** أو **Seamless**) واضغط **ابدأ**.

بعد المعالج: افتح **الاعدادات** إذا تبي تغيّر ملف التشغيل أو ملف الحفظ، أو ارجع للرئيسية واضغط **تشغيل اللعبة**. تقدر تعيد المعالج أي وقت من الاعدادات ← «فتح معالج الإعداد».

إذا كان ملف التشغيل مو موجود، بتظهر الرسالة: **«ملف اللعبة مو موجود، اختر المسار الصحيح من الاعدادات»**.

## وضعا التشغيل: Normal و Seamless

في الصفحة الرئيسية، جنب زر **تشغيل اللعبة**، فيه خيارين:

| الخيار | وش يشغّل |
| --- | --- |
| **Play Normal** | ملف `nrcs` اللي اخترته، أو `eldenring.exe` مباشرة. |
| **Play with Seamless Co-op** | ملف `launch_elden_ring_seamlesscoop.exe` مباشرة، بدون تشغيل ستيم. |

- الخيار المختار يصير **أخضر**، وينحفظ في `settings.json` ويرجع محدّد بعد إعادة فتح اللانشر.
- اللانشر **ما يشغّل ستيم أبداً** في الوضعين.
- إذا كان Seamless ناقص ملفات، يظهر زر **Test Seamless** بدل التأكيد الأخضر، ويشرح لك الناقص.

## لغة الواجهة

- زر **EN / عربي** في الشريط العلوي، وبطاقة **لغة اللانشر** داخل الاعدادات.
- التبديل فوري: العربية RTL والإنجليزية LTR، وكل النصوص والعناصر الثابتة ترجع للغتها الصحيحة.
- اللغة تنحفظ، فترجع نفس اللغة بعد إعادة فتح اللانشر.
- أسماء الشخصيات وأسماء المودات تبقى كما هي لأنها بيانات من حفظك/اللعبة.

## Seamless Co-op - Multiplayer

قسم كامل داخل **الاعدادات** بلوحة `Seamless Co-op — اللعب الجماعي`:

- **كلمة سر الكو-أوب**: كلمة سر الجلسة، تُكتب في `[PASSWORD] cooppassword` داخل `seamlesscoop.ini`. نفس الكلمة لازم تكون عندك وعند أخوياك.
- **اسم اللاعب**: الاسم اللي يظهر للاعبين، يُكتب في `steam_emu.ini` باسم `UserName` (للنسخ الريباك).
- **أقصى عدد لاعبين**: حجم الحفلة المفضّل. Seamless 2.x يدعم حتى 127 لاعب، لكن عدد اللاعبين الفعلي يعتمد على طريقة لعبك — القيمة هنا تفضيل تحفظه الواجهة ولا يفرضها ملف ini نفسه.
- **اختبار Seamless**: يفحص ملفات اللعبة و Seamless ويعرض تقريراً: كل الملفات المطلوبة، إصدار المود، crashpad، ومحتوى الاعدادات.
- **فتح seamlesscoop.ini**: يفتح ملف الاعدادات للتعديل اليدوي.
- كلمة السر تُحفظ أيضاً داخل إعدادات اللانشر، فأي تغيير من الواجهة ينزل على الملف فوراً. وفي الرئيسية زر **نسخ** ينسخ كلمة السر بضغطة عشان ترسلها لأخوياك.

### أسماء الملفات الحقيقية والبديلة

Seamless Co-op 2.0.3 ينزل بالأسماء الرسمية `ersc_launcher.exe` و`SeamlessCoop\ersc.dll` و`SeamlessCoop\ersc_settings.ini`. اللانشر يوفّر أيضاً الأسماء المطلوبة:

```text
launch_elden_ring_seamlesscoop.exe   -> ersc_launcher.exe
seamlesscoop.dll                     -> SeamlessCoop\ersc.dll
seamlesscoop.ini                     -> SeamlessCoop\ersc_settings.ini
```

الملفات البديلة مربوطة hardlinks بنفس المحتوى، فأي تعديل على الأصل ينعكس على البديل. الملفات الأصلية والبديلة كلها موجودة داخل `C:\Games\ELDEN RING\Game`.

### تجهيز نسخة جديدة بنفسك

```bash
node scripts/install-seamless.js "مسار مجلد Seamless Co-op المفكوك"
```

السكربت ياخذ نسخة احتياطية من الملفات القديمة أولاً، ثم يركّب Seamless، ويضبط `save_file_extension = co2`، وينشئ الأسماء البديلة.

### نتيجة التحقق الفعلي

تم تشغيل اللعبة فعلياً على الجهاز واختبار الوضعين:

- **Seamless**: اللعبة فتحت ووصلت لقائمة اللعبة الرئيسية، وأسفل الشاشة ظهر **Elden Ring Seamless Co-op v2.0.3 by Yui** — بدون شاشة سوداء وبدون إغلاق.
- **Normal**: اللعبة فتحت ووصلت لنفس القائمة الرئيسية، وظهرت حالة **OFFLINE** بدون أي أثر لـ Seamless.
- تم إغلاق اللعبة بعد كل اختبار. إذا ظهرت رسالة «previous session wasn't ended properly» عند أول تشغيل، اضغط **OK** مرة وحدة — سببها الإغلاق القسري أثناء الاختبار، وليست من اللانشر.
- **كلمة السر الافتراضية الحالية:** `erdtree-coop`. غيّرها من خيار **Password** قبل اللعب مع أخوياك.
- **ما تم التحقق منه:** التشغيل المحلي ووصول اللعبة للقائمة في الوضعين، ووجود ملفات Seamless وإصداره، وكتابة كلمة السر والاسم في الملفات.
- **ما لا يمكن إثباته من جهاز واحد:** دخول لاعب ثانٍ فعلياً ومزامنة الجلسة بين حسابين. هذا يحتاج جهاز/حساب ثاني بنفس كلمة السر؛ إعدادات الملفات واللانشر جاهزة له.

## Friends & Invites — الأصدقاء والدعوات

قسم **Friends** إنجليزي (LTR) بتصميم فخم يشبه Steam:

- **Add Friend**: أضف بالكود (`ER-XXXX-XXXX`) فوراً، أو اكتب اسم اللاعب — البحث **حيّ** أثناء الكتابة بين المتصلين الآن، ويعرض لكل نتيجة مستواها ونبذة عنها وزر **Add / Pending / Friend**.
- **قائمة الأصدقاء**: صورة رمزية، الاسم، شارة المستوى، الحالة **Online / In Game / Offline / Main Menu**، وآخر نشاط داخل اللعبة.
- **ملفك الشخصي**: بطاقة **You** فيها اسمك وكودك وستات حقيقية من جهازك (أعلى مستوى، عدد الشخصيات، المودات المثبتة، البيلدات)، وزر **Edit Profile** لتغيير الاسم وكتابة **About me** (حتى 300 حرف). البروفايل والستات و«About me» تنتشر لأصدقائك على الريلاي وتتحدث لحظياً.
- **التنبيهات**: مفتاحان منفصلان — نافذة منبثقة فوق اللعبة، وصوت تنبيه — ينطبقان على الرسائل والدعوات وطلبات الصداقة. تقدر تطفّي أي واحد منهم من بطاقة **Notifications**.
- لكل صديق: **Invite** (دعوة)، **Join** (طلب دخول — صاحب الجلسة يرد تلقائياً بدعوة)، **Chat** (محادثة كاملة مع عداد غير مقروء، وفيها نبذة الصديق وستاته أعلى المحادثة).
- **الدعوة داخل اللعبة**: لما تكون اللعبة شغالة واللانشر مو عليه تركيز، تظهر نافذة صغيرة شفافة فوق الشاشة:
  «فلان يدعوك للعب — [ Accept ] [ Decline ]». Accept يزامن كلمة سر Seamless ويكمل الدخول بدون كتابة باسورد.
- المحادثة توصل حتى وأنت داخل اللعبة (تظهر في نفس النافذة، وتقدر ترد منها).
- **Join** يرسل طلب دخول؛ صاحب الجلسة يستلمه وتوصل لك دعوة تلقائية بضغطة Accept.
- التقنية: قناة MQTT عامة (`broker.emqx.io` مع بديل `broker.hivemq.com`)، ورسائل الشات والدعوات مشفّرة **AES-256-GCM** بمفتاح مشترك بين الصديقين.
- **ملاحظة صريحة:** لما تكون داخل العالم أصلاً، اللانشر يزامن الباسورد ويقول لك تستخدم الـ Effigy داخل اللعبة — ما يقدر يحرّك شخصيتك من خارج اللعبة بدون حقن.

## Auto Update — التحديثات (GitHub Releases)

- المصدر الرسمي للتحديثات هو **GitHub Releases** لمستودع اللانشر. يُضبط مرة واحدة: إما عبر ثابت `OFFICIAL_REPO` في `src/main/updater.js` (يحقنه سكربت الإصدار)، أو يدوياً من الاعدادات ← Updates ← حقل **GitHub repository** بصيغة `owner/name`.
- أول ما يفتح اللانشر يفحص `releases/latest` (إذا مضبوط المستودع) بدون ما يعطل التشغيل.
- إذا فيه إصدار أحدث تظهر نافذة **New Update Available — vX.X** مع قائمة التغييرات (من وصف الإصدار في GitHub) وزرين **Update Now** / **Later**، وشريط تقدم أثناء التنزيل.
- **الأمان**: لا يُعرض تحديث إلا إذا نشر GitHub بصمة SHA-256 للحزمة؛ التنزيل محصور بنطاقات GitHub؛ أي ملف تفشل بصمته يُحذف ولا يُثبّت أبداً؛ التنزيل المتقطع يُستأنف تلقائياً (Range).
- **Update Now** ينزّل الحزمة الكاملة (مثبّت أو portable حسب نوع نسختك)، يتحقق من البصمة، ثم يركّبها بعد إغلاق اللانشر ويعيد فتحه. **ما يمسح** الإعدادات ولا الشخصيات ولا الأصدقاء ولا البيلدات ولا الحفظات — كلها في `userData` خارج مجلد التطبيق.
- قسم **Updates** في الاعدادات فيه **Check for Updates** يدوي، رقم النسخة الحالي، وحقل المستودع.
- رقم النسخة ظاهر تحت في الشريط الجانبي: `Version 2.7.0`.

### نشر إصدار جديد (للناشر فقط)

```bash
node scripts/prepare-release.js --repo owner/name --version 2.8.0 --notes "Fix A;Added B"
# يراجع الناشر المخرجات ثم ينفّذ أمر النشر المطبوع:
```

## المودات

### ورشة المودات — تنزيل ثم تفعيل

الورشة فيها **300 مود حقيقي** من Nexus Mods (بصورهم الأصلية) وفهرس كامل بتبويبين: **Discover** (استكشاف) و**MY MODS** (موداتك).

- **Discover**: بحث فوري، شرائح تصنيفات (Gameplay, Graphics, Co-op, Boss, Quality of Life, Cheat/Fun, New Weapons, New Bosses, Map, Sound…)، وفلاتر (All, Downloaded, Activated, Popular, New). كل بطاقة فيها الصورة الأصلية، الاسم، التحميلات، التقييم، ووصف إنجليزي من سطرين.
- **صفحة المود**: وش يسوي، كيف تستخدمه، هل آمن مع Co-op؟ (Yes/No) مع تحذير أحمر واضح للمودات اللي تكسر Co-op، الحجم، الإصدار، والكاتب.
- **خطوتين منفصلتين**:
  1. **Download** ينزّل الملف **داخل اللانشر** (مع شريط تقدم) ويخزنه في `downloads\<id>\`، ثم **يفكّه ويركّبه تلقائياً في مكتبة المودات وهو مطفأ**، وتظهر الحالة **Ready**.
  2. بعدها يظهر في **MY MODS**، تضغط **Activate** فينسخ المود داخل اللعبة ويفعّله في Mod Engine 2، أو **Deactivate** فيبقى منزّل بدون تفعيل. تقدر تفعّل عدة مودات مع بعض، وفيه **Activate All** / **Deactivate All** / **Delete**.
- **PLAY** يشغّل اللعبة بالمودات **المفعّلة فقط**.
- **بدون متصفح خارجي وبدون اشتراك**: كل مود له زر **Download**. المودات ذات المصدر المجاني المباشر (GitHub Releases مثل Seamless Co-op وElden Mod Loader، أو رابط مرآة مجاني يحفظه اللاعب اختيارياً) تنزل بالخلفية بدون أي نافذة. مودات Nexus فقط تفتح **نافذة نيكسس داخل اللانشر نفسه**: نيكسس يشترط تسجيل دخول لأي تحميل حتى المجاني، فتسجّل دخول مرة واحدة (الجلسة تنحفظ)، وتضغط زر التحميل المجاني حق نيكسس مرة واحدة — واللانشر يلتقط الملف ويكمل الفك والتركيب تلقائياً. ما فيه أي ضغط أو تجاوز آلي عنك: الضغطة ضغطتك أنت.
- **بدون صور وهمية**: صور المودات هي thumbnails Nexus الأصلية نفسها (299 صورة محلية)، وأي مود بدون صورة يظهر بحرف اسمه بدل صورة مزيفة.
- **إزالة آمنة**: المود ينتقل إلى **سلة المحذوفات** (Recycle Bin) مو حذف نهائي.

### التركيب اليدوي (الطريقة القديمة باقية)

- **تركيب مود من ملف**: اختر ملف `.zip` (أو `.7z` / `.rar` إذا الأدوات متوفرة)، واللانشر يفك الضغط ويركّبه بنفسه.
- **Free mirror link (اختياري)**: من تفاصيل المود تقدر تحفظ رابط أرشيف مجاني (`.zip` / `.7z` / `.rar`)؛ روابط Google Drive وDropbox تتحول تلقائياً لرابط مباشر، واللانشر ينزّل الملف بالخلفية بدون أي نافذة. بديل اختياري لنافذة نيكسس.
- المود غير المتوافق يظهر تحته: **«هذا المود مو متوافق مع نسختك»**، ويتوقف تلقائياً وما ينطبق على اللعبة.
- **تطبيق على اللعبة** ينسخ المودات المفعّلة ويحدّث `config_eldenring.toml` لـ Mod Engine 2. لازم يكون Mod Engine 2 موجود داخل مجلد اللعبة للمودات اللي تحتاجه.

## التعديلات (Trainer)

تفتحها من **الاعدادات → أدوات إضافية → التعديلات**.

- تعمل **أوفلاين فقط**، واللانشر ما يتجاوز Easy Anti-Cheat ولا يخفي نفسه. التعديل أونلاين مسؤوليته على المستخدم.
- لازم تكون اللعبة شغالة عشان يتصل اللانشر بعملية `eldenring.exe`.
- كل تعديل له مفتاح مستقل (أخضر = شغال، رمادي = طافي)، وفيه **تشغيل الكل** و**إيقاف الكل** و**حفظ تشكيلتي**.
- **Global Offsets** تبدأ فاضية. إذا ما عندك عنوان جاهز، استخدم **فاحص القيم**:
  1. اكتب القيمة الحالية (مثلاً عدد الرونز) واضغط **بحث أول**.
  2. غيّر القيمة داخل اللعبة وارجع اكتب القيمة الجديدة واضغط **بحث تالي**.
  3. احفظ العنوان من النتيجة، وبيصير التعديل قادر ينطبق.
- البريستات الجاهزة تطبق مجموعة تعديلات مرة وحدة، وتقدر تحفظ تشكيلتك الخاصة.

## الشخصيات والحفظات

تفتحها من **الاعدادات → أدوات إضافية** أيضاً.

- أسماء الشخصيات ومستوياتها تنقرأ من حفظ Elden Ring نفسه.
- لكل شخصية صفحة تعديلاتها الخاصة. تفعيل شخصية يطبق تعديلاتها المختارة فقط، وإيقافها يوقفها.
- **مدير الحفظ** يعرض الحفظ الحالي ونسخك الاحتياطية، ولكل نسخة تاريخ واسم وأزرار: **تحميل** / **نسخ احتياطي** / **حذف**.
- قبل الاسترجاع لازم تكون اللعبة مسكّرة. اللانشر يسوي نسخة أمان تلقائية قبل الاستبدال.
- النسخ الاحتياطية تنحفظ داخل بيانات اللانشر، والحفظات المكتشفة تُعرض من مجلد اللعبة عندك.

## MY SAVES — كل شخصياتك في مكان واحد

قسم مستقل في الشريط الجانبي (إنجليزي LTR) يقرأ **حفظك أنت** مباشرة من `ER0000.sl2`:

- **البطاقات**: Slot، اسم الشخصية، المستوى، وقت اللعب، و Last boss / Location. الاسم والمستوى ووقت اللعب **قيم حقيقية** من جدول ملخص الحفظ؛ آخر بوس والموقع **ما هم مخزّنين** في هذا الجدول، فتنعرض `—` مع ملاحظة صريحة بدل تخمين.
- **Use This Save** يحدد الشخصية النشطة للتعديلات والبيلدات وللـ PLAY القادم. **حد صريح:** إلدن رينغ تعرض شاشة اختيار الشخصية بنفسها — ما فيه لانشر يقدر يتخطاها.
- **Backup** / **Restore**: الاسترجاع يرفض إذا اللعبة شغالة، وياخذ **نسخة أمان** من حفظك الحالي قبل الاستبدال. **Rename** يغيّر اسم العرض داخل اللانشر فقط (الشخصية والملف ما يتغيرون). **Delete** يسأل **Are you sure؟** ثم **يخفي** الشخصية من القائمة فقط — ملف الحفظ **ما ينمسح أبداً**، وتقدر ترجّعها من قسم Hidden.
- **BACKUPS**: قائمة بكل النسخ بالتاريخ والوقت مع استرجاع بضغطة.
- **Auto backup**: كل مرة تسكّر اللعبة، اللانشر ينتظر ثواني ثم ياخذ نسخة تلقائية من الحفظ — وما يكررها إذا الملف ما تغيّر (مقارنة وقت التعديل والحجم).
- **Create New Save Slot**: نسخة كاملة من حفظك الحالي باسم تختاره (مثلاً «Before Radahn») ترجع لها بضغطة. إنشاء الشخصيات نفسها يصير داخل اللعبة، والشخصيات الجديدة تظهر هنا تلقائياً بأول قراءة/فتح.
- **لا تعديل ولا حقن في `ER0000.sl2`**: كل أوامر MY SAVES إما تقرأ، أو تنشئ نسخة، أو تستبدل الملف بنسخة كاملة مع نسخة أمان أولاً.

## UNLOCK ALL — فتح المحتوى بطريقة آمنة

قسم مستقل (إنجليزي LTR) فيه صناديق اختيار وزرّي **APPLY UNLOCK** / **REMOVE UNLOCK**:

- **الأسلحة (مع Shadow of the Erdtree) / الدروع / التعويذات / السحر / Ashes of War / Spirit Ashes / المواد**: توصل عبر مود حقيقي اسمه **Glorious Merchant** (Nexus 5192). اللانشر ينزّله ويركّبه **داخل اللانشر** ثم يفعّله — كل شي يصير مجاني عند تاجر **Twin Maiden Husks**، بما فيه محتوى DLC.
- **ليش مو كتابة مباشرة في الحفظ؟** لأن كتابة آلاف عناصر الإنفنتوري داخل `ER0000.sl2` هي أسرع طريق لتخريب الحفظ. اللانشر ما يسويها. **الحد الصريح:** العناصر تجيك من التاجر (تشريها بـ 0 رونز)، مو تنزل كلها في الحقيبة/الصندوق لحالها.
- **Max Runes**: تعديل ذاكرة حقيقي يثبّت الرونز على 999,999,999 أثناء تشغيل اللعبة.
- **Max Level**: يكتب 99 في كل الـ 8 صفات (مستوى 713). اللانشر يقرأ صفاتك **قبل** الكتابة ويخزّنها، فزر **REMOVE** يرجّعها. إذا اللعبة مو شغالة/التعديل مو متصل، الطلب ينحفظ كـ Queued وينفّذ أول ما يتصل.
- **REMOVE UNLOCK**: يوقف مود التاجر، يوقف تثبيت الرونز، ويرجّع صفاتك القديمة إذا كانت محفوظة.
- **تحذير ظاهر في القسم**: **Use in single player or with friends only** — لا تستخدم العناصر أو القيم المفتوحة في جلسات أونلاين عامة، واللانشر ما يتجاوز Easy Anti-Cheat.

## إرسال اللانشر لأخوياك

النسخة الجاهزة للتوزيع هي `Erdtree-Launcher-Setup-2.7.0.exe` (مثبّت مع اختصارات قائمة ابدأ وسطح المكتب) أو `Erdtree-Launcher-2.7.0-portable.exe` (بدون تثبيت) من أحدث مجلد `release-*`. أرسل الملف نفسه فقط:

1. أخوك يشغّل الملف (ما يحتاج تثبيت). ويندوز قد يعرض تحذير SmartScreen لأن الملف غير موقّع — «More info» ثم «Run anyway».
2. يفتح **معالج أول مرة** تلقائياً ويدوّر على اللعبة بنفسه. إذا ما لقاها يختار ملف التشغيل يدوياً.
3. يكتب **نفس كلمة السر** اللي اخترتها، ويضغط «ثبّت Seamless» إذا مو مثبّت عنده (تحميل مباشر من GitHub).
4. يختار **Play with Seamless Co-op**، وبعدها تدخلون نفس العالم.

ملاحظات مهمة للأصدقاء:

- التعديلات كلها **أوفلاين/Solo فقط**. استخدامها أونلاين قد يبند الحساب.
- الورشة تنزّل داخل اللانشر: مصدر مجاني مباشر للمودات اللي لها مرآة، ونافذة نيكسس داخلية (دخول مرة واحدة + ضغطة واحدة) للباقي — **بدون متصفح خارجي وبدون اشتراك**. وتقدر تستورد أرشيف عندك بزر **Import**.
- بعض التعديلات تحتاج اللانشر بصلاحيات مسؤول إذا كانت اللعبة نفسها شغالة كمسؤول — اللانشر يكتشفها ويعرض زر «إعادة التشغيل كمسؤول» تلقائياً.
- حفظات اللعبة والمودات تبقى على جهاز كل شخص؛ لا شيء يتزامن بينكم غير كلمة سر Seamless.

## التغليف (بناء نسخة توزيع)

```bash
npm run package      # مجلد جاهز للتشغيل في release/win-unpacked
npm run package:win  # مثبّت NSIS + نسخة portable في release-*
```

أو بضغطة مزدوجة على `package.bat`.

إذا كان مجلد `release` موجود ومقفول من مضاد الفيروسات أو فهرس ويندوز، السكربت يبني تلقائياً في مجلد جديد باسم `release-<وقت>` ويطبع المسار النهائي. تقدر تحذف المجلدات القديمة لاحقاً بعد ما يتحرر القفل.

للإصدار الرسمي استخدم `scripts/prepare-release.js` (يبني في `release-<version>` جديد ويجهّز ملاحظات الإصدار والبصمات — انظر قسم التحديثات). المثبّت باسم `Erdtree-Launcher-Setup-<version>.exe` والportable باسم `Erdtree-Launcher-<version>-portable.exe`. المثبّت assisted: يختار المستخدم مجلد التثبيت، وينشئ اختصار قائمة ابدأ واختصار سطح المكتب، وإزالة التثبيت **لا تحذف** بيانات المستخدم.

ملاحظات:

- الإعداد يستخدم Electron المثبّت محلياً (`build.electronDist`) عشان ما يعيد تنزيله، ونتجنب قفل الملفات على ويندوز. إذا حذفت `node_modules`، شغّل `npm install` أول.
- المثبّت غير موقّع (بدون شهادة Code Signing). ويندوز قد يعرض تحذير SmartScreen، وهذا طبيعي للتطبيقات غير الموقّعة.
- الأيقونة من `assets/icon.ico`، وتُستخدم في المثبّت والتطبيق.

## أين تنحفظ البيانات؟

المسار الافتراضي على ويندوز:

```text
%APPDATA%\Erdtree Launcher\
├── accounts.json          # الحسابات (اسم، إيميل، hash كلمة السر + salt، كود استرجاع مجزّأ، صورة)
├── session.json           # جلسة Remember Me (token مجزّأ، صلاحية 45 يوم)
└── profiles\<account-id>\
    ├── settings.json      # الإعدادات الخاصة بالحساب
    ├── characters.json    # تعديلات وبيلد كل شخصية + الستات المعلّقة
    ├── builds.json        # بيلداتك المحفوظة + آخر بيلد مركّب على كل شخصية
    ├── social.json        # هويتك (كود الصداقة)، الأصدقاء، الطلبات، المحادثات
    ├── downloads.json     # أرشيفات الورشة + روابط المرآة المجانية الاختيارية + حالتها (downloaded / active / ready)
    ├── unlocks.json       # اختيارات UNLOCK ALL + الصفات السابقة للاسترجاع
    ├── mods\              # المودات المثبتة
    ├── downloads\<id>\    # أرشيف كل مود نزّلته الورشة قبل التفعيل
    └── save-backups\      # النسخ الاحتياطية للحفظ (يدوية / تلقائية / Save Slots)
```

ملف `accounts.json` وسجل الجلسة في جذر `userData`، وكل شي آخر داخل مجلد الحساب. **Guest** يستخدم مجلداً مؤقتاً يُمسح عند الخروج.

حفظات اللعبة نفسها تكون عادةً في:

```text
%APPDATA%\EldenRing\<SteamID>\ER0000.sl2
```

روابط المرآة المجانية الاختيارية تنحفظ داخل `downloads.json` لكل حساب، واللانشر يستخدمها تلقائياً بالمرات الجاية — ما تحتاج تعيد لصقها. وجلسة دخول نيكسس تنحفظ في partition خاص داخل اللانشر، فما تعيد تسجيل الدخول كل مرة.

## حل المشاكل الشائعة

| المشكلة | الحل |
| --- | --- |
| **«ملف اللعبة مو موجود…»** | افتح الاعدادات واختر ملف `nrcs` الصحيح. |
| **«كرتك ما يدعم DLSS»** | بطاقتك ما تدعم DLSS؛ خلّ الخيار على **إيقاف**. |
| **«هذا المود مو متوافق مع نسختك»** | المود معمول لنسخة لعبة مختلفة. ركّب نسخة متوافقة، أو انتظر تحديث المود. |
| التعديلات ما تتصل | تأكد أن اللعبة شغالة، وأن اللانشر واللعبة بنفس صلاحيات التشغيل، وجرّب أوفلاين. |
| بحث Nexus يعطي 401 | المفتاح غير صحيح أو منتهي؛ احفظ مفتاح جديد. |
| مود Nexus يطلب دخول | نيكسس يشترط تسجيل دخول لأي تحميل حتى المجاني. اضغط **Download** فتفتح نافذة نيكسس داخل اللانشر: سجّل دخول مرة واحدة (ينحفظ) واضغط زر التحميل المجاني مرة — الباقي تلقائي. أو احفظ رابط مرآة مجاني من التفاصيل، أو **Import** أرشيف عندك. |
| الاسترجاع يرفض | سكّر اللعبة أول، ثم أعد المحاولة. |
| **Seamless Fatal Error: enter a session password** | اكتب كلمة سر في **الاعدادات → Seamless Co-op → Password**، أو شغّل `Test Seamless` ثم أعد المحاولة. Seamless 2.0.3 ما يفتح بدون كلمة سر. |
| Seamless يفتح ثم يرجع سطح المكتب | تأكد أن Steam شغال بالخلفية (النسخة الريباك تحتاجه)، وأن `seamlesscoop.dll` و`SeamlessCoop\ersc.dll` موجودين، ثم اضغط **Test Seamless**. |
| البناء يفشل بـ EBUSY/EPERM | مضاد الفيروسات أو الفهرس يقرأ ملفات `asar`؛ أعد المحاولة أو أخرج مجلد البناء من مجلد مراقب. |
